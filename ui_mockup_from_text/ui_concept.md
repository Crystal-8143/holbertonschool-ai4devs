# UI Concept - Job Application Tracker

## Purpose
Help job seekers organize their job search by tracking applications, interview stages, and follow-ups in one place, so nothing falls through the cracks.

## Users
- Active job seekers: manage many applications at once
- Students and graduates: track internships and entry-level applications
- Career changers: keep notes and compare roles across different industries

## Core Screens
- Dashboard with application stats, upcoming interviews, and follow-up reminders
- Applications list with search, status filters, and sorting
- Add/Edit Application form (company, role, link, date, salary, notes)
- Application detail view with status timeline, contacts, and notes
- Pipeline board showing applications by stage (Applied, Interview, Offer, Rejected)

## Actions
- Add a new application
- Edit or delete an application
- Update application status
- Filter and search applications
- Set follow-up reminders
- Add notes and contact details
