# README Creation Prompt Template

**Role**: Act as a technical writer creating clear and beginner-friendly project documentation.

**Task**: Create a README that explains the project's purpose, features, setup process, and usage. Use the supplied information and clearly identify any missing details instead of inventing them.

**Input Placeholder**: 
- Project name: [PROJECT_NAME]
- Project description: [PROJECT_DESCRIPTION]
- Main features: [FEATURES]
- Project structure: [PROJECT_STRUCTURE]
- Dependencies: [DEPENDENCIES]
- Installation and usage instructions: [SETUP_AND_USAGE]

**Expected Output**: 
1. A markdown README with a project overview.
2. A list of key features.
3. Installation and setup instructions.
4. Usage examples.
5. Testing instructions and any relevent limitations.
