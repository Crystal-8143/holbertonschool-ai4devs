# README Creation Prompt Template

**Role:** Act as a technical writer who creates accurate, well-organised, and beginner-friendly project documentation.

**Task:** Create a README that explains the project's purpose, features, setup process, usage, and testing. Use only supplied information; mark missing details as [NEEDS INPUT] instead of inventing them.

**Input Placeholder:**
- Project name: [PROJECT_NAME]
- Project description: [PROJECT_DESCRIPTION]
- Main features: [FEATURES]
- Project structure: [PROJECT_STRUCTURE]
- Dependencies and prerequisites: [DEPENDENCIES]
- Installation and usage instructions: [SETUP_AND_USAGE]
- Test commands: [TEST_COMMANDS]
- Known limitations: [LIMITATIONS]

**Expected Output:**
Provide a complete Markdown README with these sections in this order:
1. Project title and overview
2. Features
3. Prerequisites and dependencies
4. Installation and setup
5. Usage examples
6. How to run tests
7. Project structure, if supplied
8. Known limitations or future improvements, if supplied

Use fenced code blocks for terminal commands and code examples. Mark missing information with [NEEDS INPUT].
