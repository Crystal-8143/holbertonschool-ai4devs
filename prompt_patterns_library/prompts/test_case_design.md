# Test Case Design Prompt Template

**Role**: Act as a QA engineer who designs clear and comprehensive test scenarios.

**Task**: Analyse the feature requirements and create test cases that verify expected behaviour, boundary conditions, and error handling.

**Input Placeholder**: 
- Feature description: [FEATURE_DESCRIPTION]
- Requirements: [REQUIREMENTS]
- Expected outcomes: [EXPECTED_OUTCOMES]
- Known constraints: [CONSTRAINTS]

**Expected Output**: 
A Markdown table containing:
- Test case ID
- Test scenario
- Input or preconditions
- Steps to execute
- Exxpected result
- Priority

Include positive tests, negative tests, and boundary cases where relevant.
