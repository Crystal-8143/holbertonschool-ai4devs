# Function Documentation Prompt Template

**Role**: Act as a technical writer with experience documenting software functions.

**Task**: Document the provided function so that another developer can understand its purpose, parameters, return value, and possible errors. Do not invent behaviour that is not supported by the code or requirements.

**Input Placeholder**: 
- Programming language: [LANGUAGE]
- Function code: [FUNCTION_CODE]
- Intended behaviour or additional context: [FUNCTION_CONTEXT]
- Documentation format: [DOCUMENTATION_FORMAT]

**Expected Output**: 
1. Documentation in the requested format, such as JSDoc or Python docstrings.
2. Descriptions of parameters and return values.
3. Relevant exceptions, errore, or edge cases.
4. A short usage example if apprpriate.
